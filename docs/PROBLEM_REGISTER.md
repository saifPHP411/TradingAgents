# سجل المشاكل — مراجعة TradingAgents

> **النطاق:** سجل أدلة ومشاكل المرحلة 1 فقط. هذا الملف لا يثبت الجاهزية للتداول ولا يجيز تشغيل Worker أو إرسال أوامر.
>
> **تاريخ خط الأساس:** 2026-11-14. الحالات أدناه تعكس مراجعة المرحلة 0 ونتائج CI التي جُمعت خلالها؛ يجب تحديثها إذا تغيرت الفروع أو نتائج CI.
>
> **حدود التحقق:** لم تُنفذ في المرحلة 0 اختبارات محلية مستقلة أو اتصالات تداول حقيقية. نتائج CI أدناه أدلة تشغيل آلي على SHA محدد، وليست إثباتاً لصحة التنفيذ في Bybit Demo أو لربحية الاستراتيجية.

## تعريف الحالات

- **متحقق:** أعيد إنتاجه مستقلاً أو تؤيده نتيجة CI/سجل/أمر مباشر محدد.
- **مُبلَّغ عنه:** ورد في تقرير سابق أو ملخص/وكيل آخر ولم يُعَد إنتاجه في هذه المراجعة.
- **غير مثبت:** لم يتوفر دليل كافٍ لإثباته أو نفيه.
- **جزئي:** يوجد تنفيذ أو اختبار يغطي جزءاً من معيار القبول، لكن السلوك الكامل لم يثبت.
- **مفتوح:** لم يثبت الإصلاح أو ما زال هناك إخفاق/فجوة قبول.

## أولويات وبوابات التقدم

1. **Gate 0 — صحة التنفيذ:** P1–P4. لا انتقال قبل إثبات التوجيه، العزل، الحماية، والتعامل المتسلسل مع التعبئات الجزئية.
2. **Gate 1 — المحاسبة:** P8. يلزم دفتر متسق واختبارات invariants ومطابقة موثقة.
3. **Gate 2 — قواعد المنصة:** P5 وP7. يلزم preflight صحيح لكل أداة/وسيط وحساب dust.
4. **Gate 3 — واقعية التنفيذ:** P9. لا يكفي markout؛ يلزم نموذج دخول/خروج وتكاليف ونتائج صافية.
5. **Gate 4 — البحث الاستراتيجي:** لا يُقبل ادعاء أفضلية قبل فرضية ومعايير قبول مثبتة مسبقًا، وholdout جديد غير مستخدم، واختبارات بعد التكاليف وتوزيعات زمنية/أصول/أنظمة سوق.
6. **Gate 5 — تقرير الجاهزية:** حتى اجتياز البوابات السابقة لا يعني تشغيلًا تلقائيًا؛ قرار أي تجربة Demo صغيرة يبقى للمستخدم وحده وبموافقة منفصلة.

## ضوابط إلزامية

- كل مشكلة تُعالج لاحقًا في فرع معزول وDraft PR مستقل؛ لا دمج لأي PR دون موافقة صريحة.
- لكل إصلاح: أضف اختبار regression أولًا، وثّق فشله قبل التعديل، ثم أصلح بأقل تغيير، وأثبت نجاح الاختبار نفسه، ثم شغّل كامل الاختبارات وRuff وclean install.
- لا تحذف اختبارات ولا تخفف assertions أو حدود القبول لتجاوز الفشل.
- لا تشغيل Worker، ولا أوامر Demo/Live/Production، ولا تغيير Railway أو متغيراته أو أسراره.
- لا تفعيل SHORT أو leverage ولا رفع حدود المخاطر.
- لا تجاوز قيود الوصول الجغرافي أو 403.
- لا تعتبر نجاح CI إثباتًا للربحية؛ ولا تعتبر Markout ربحًا محققًا.
- أي سبب جذري غير مؤكد يبقى موسومًا بأنه فرضية/غير مثبت حتى تؤيده إعادة إنتاج ودليل.
